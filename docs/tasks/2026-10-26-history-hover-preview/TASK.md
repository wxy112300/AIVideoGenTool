# 历史封面 hover 预览防黑屏

- 状态：完成；影响：patch。
- 用户要求：鼠标滑过历史封面预览时避免加载黑屏／亮度骤变，可用简洁等待指示与过渡。
- 范围：封面到预览的显示时机与取消；保留静音、hover 意图延迟、减少动态策略、虚拟列表与媒体释放规则，不改生成或持久化合同。

## Resume

已定位：原逻辑开始 load/play 即加 playing，CSS 同时隐藏封面并显示尚无首帧的视频；全幅加载层又压暗画面。改为封面始终留在视频下方，requestVideoFrameCallback 确认当前 seek 的可呈现帧后以 140ms 淡入视频，等待超过 250ms 只显示底部中间小指示，避开右下角评分。离开／切卡／取消／错误／卸载清理回调与计时器，旧 hover 或播放拒绝不回写新会话。没有帧回调时用已解码数据与 rAF 回退；加载提示三语改为“预览”，短文案仅视觉隐藏，仍可供辅助技术读取。
