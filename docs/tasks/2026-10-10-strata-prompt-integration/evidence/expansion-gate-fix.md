# H3 影视细节扩写门禁修复

日期：2026-10-14。用户授权修复校验bug；patch级，不改版本号，不下载/运行模型，不改变用户原稿或队列。

## 问题与修复

- 原规则已包含原稿词数增长底线：`max(模式/时长底线, 原稿词数 + max(40, ceil(原稿词数 * 0.2)))`。本轮保留该规则，不以降低词数目标换取“通过率”。
- 原来在程序修复对白、镜头、尺度、连续性以后才验收，程序补句会虚增词数。现在共享normalizer在传输包装清理后、内容修复前验证模型自己的时间线；Strata、ComfyUI多模态、QwenVL PEFT、native、H3 Writer及保留的llama/LM Studio适配一致传递preset。Writer原有最多两次修复仍在，但不能用程序补句当作模型补写。
- 只计官方主时间线；包装/前言、R2V主体清单/摘要、声场和配乐不顶替动作正文。`[Shot N]`等结构标签、时间码不计为扩写细节。重复主字段拒绝，多镜头仍写在一个字段内。
- 去重完全相同的填充句后计数；若源稿本身含同句多次，保留对应重复额度。不能据此宣称能识别所有近似复述或空话。
- 在原有词数底线之外，中英文描述脚本相同的情况还要求有效字母/汉字/数字字符数不短于原稿；去掉批注、结构标签，不用空格、标点凑长度。对白/可见字不参与描述脚本判定；这只是中文/非中文脚本启发式，不是通用多语种语义长度指标。
- 原词面门禁对中文“开门”→“门向内开启”、“转头”→“头部向右转动”容易误判。现允许同句短近邻范围内保留相同汉字的拆词/换序；明显不相关文本仍失败。它不能证明主体归属、否定、动作顺序、完整同义替换或跨语言语义无遗漏，真实质量仍需人工对照。
- 尺度helper识别自己已经插入的精确锁，重复恢复不再生成三段同句；已识别且逐字一致的引号对白原位转为规范标签，不再另外补一次广播。新增广播/播报语音提示，旁边的标牌文字仍保留。
- 只有详细预设执行增长门禁，精简/其他预设和定向批注修改保持原路径。精确对白、可见字与原Draft/version/异步origin保护仍保留。
