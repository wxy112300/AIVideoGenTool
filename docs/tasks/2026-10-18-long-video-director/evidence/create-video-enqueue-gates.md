# 图生视频入队阻塞清单

核对 Create 的「图生视频」页，同页的纯文本、首尾帧、关键帧、R2V 和 Continuum 多段都在范围内。续写、图像生成以及队列开始后才发生的验证另走各自的入口。保留原清单的编号，方便对照反馈。一个任务可同时违反多个条件，界面一般只显示优先级最高的一条。

## 第一步，按钮暂不可用

1. **正在提交。** 上一次点击尚未返回，期间按钮禁止重复提交。点击处理器也要求当前草稿可读。
2. **正在进行首次环境扫描。** 原生页在扫描中且没有可用的旧结果时暂时等待。已取到扫描结果后按实际配置检查。当前多段按钮走独立检查。
3. **首帧缺失已放行。** 无图时使用工作流的纯文本入口。支持尾帧的 H3 原生和 Continuum FL2VA 多段均接受仅尾帧。
4. **原生提示词为空。** 空白字符也算空。多段检查各段的正文；全局可以为空。
5. **关键帧时间冲突或引用无效。** 缺图或缺时间的槽显示警告并跳过。已填写的时刻超出时间轴或量化到同一帧时阻塞。提示词引用空槽、缺时间的槽或不存在的 `<Picture N>` 时阻塞。原生按原生时长，多段按整片布局。
6. **R2V 引用无效。** 空槽显示警告。提示词引用空槽或不存在的 Picture／Video 时阻塞。没有引用时可提交。多段 R2V 的有效参考限图片、最多 9 张。执行时只传有媒体的槽，并同步换算实际采样提示词里的引用编号。
7. **原生缺工作流路径。** 已选模型还没有可提交的 API 工作流。
8. **当前设置超出原生生成限制。** 时长或 FPS 无效、时长超过该模型的上限、分辨率超出模型选项或合法自定义范围、生成帧数超过预算。H3 1080p 在预览检查中按 720p 首采样的尺寸资格处理，再由提交预检核对两段工作流。
9. **模型或加速要求的 ComfyUI 不可用。** 扫描确定版本低于所选模型的硬性要求；Turbo 的已检查 core 缺少支持；Pi-H3 的 piFlow 缺失、运行中节点未就绪，或所选 2 步／4 步的必要模型文件缺失。
10. **LoRA 不能按当前配置加载。** 内置 Turbo 或所选 LoRA 文件缺失，已知 SLA Turbo 节点缺失或未加载。LoRA 硬冲突包括模型或输入模式不兼容、退役条目、指定参考图片／视频数量不符、必需设置冲突、禁止的混搭以及同时使用多个相容的低步数变体。比例建议、排序建议和其他 warning 仅提示。
11. **原生 Spectrum Balanced 不可用。** 当前模型／设置不支持该模式，或者扫描未确认节点已加载。
12. **多段路由或采样策略不支持。** 新建多段限当前接通的 H3 FL2VA／支持的 H3 R2V；所选 LoRA 或 H3 执行策略有硬冲突，例如要求专用 LoRA 的 Native SLA、要求受支持检查点的 VSA，或稀疏路径与 Attention 不兼容。
13. **多段布局或段落内容未齐。** 时长与段数未确认、改过布局尚未重新确认，或者仍有空白段。每段有内容就可采用手写稿、大纲、锁定稿或带复核提示的稿。用户的活动版本原样冻结入队。
14. **多段离线依赖未满足。** 已有扫描时检查相应 H3 模型可用性、Continuum ≥ 3.10.2、Local Video Studio H3 AV ≥ 0.4.0，使用非首帧的定时引导时 AV ≥ 0.4.4。缺失、版本不符或报告不兼容都可以挡住按钮。

## 第二步，按钮可点但提交失败

主进程重新校验草稿、始末帧、关键帧和多段脚本，能拦住与界面检查之间发生的状态变化。以下是这层另外能拒绝的条件。

1. **草稿走错入口，或模型不支持图生视频。** 例如把续写草稿送进 generation，或绕过模型选择传了不支持图生视频的模型。
2. **工作流读取或 API 格式有问题。** 路径缺失、文件不存在或无权读、JSON 解析失败、拿 UI 导出图充当 API 图、图为空、节点结构／类型／输入字段错误，或缺少必需的提示词、媒体占位符且没有识别出的纯文本路由。H3 输入变化可能切到同系列的另一份工作流，也会验证实际选中的那份。缺 seed／输出名占位符在通用校验里只给警告。
3. **工作流不具备输入能力。** 用户提供有效关键帧时，实际工作流没有可用的关键帧输入结构，或提供尾帧但当前原生工作流缺少尾帧入口。多段检查自己的模型和实际参考类型。
4. **原生高分辨率配置不可执行。** 1440p 不开放；原生 1080p 要求 H3 Base FL2VA、允许保存 JointAV、当前不带视频 LoRA。两份 1080p 工作流可能读不出或未通过静态合同。已有扫描时，学习型 latent 升级的集成、权重、节点或兼容状态也可能导致拒绝。多段走独立尺寸路径。
5. **PDD／VSA 或 Turbo 与实际工作流不匹配。** 当前 PDD LoRA 或 VSA 检查点要求 PDD 采样结构，Turbo 要求对应的采样配方。能选到模型或 LoRA 不证明所用 API 图支持它。
6. **H3 配置不合法。** Q3 GGUF 不能带视频 LoRA，也不能使用 Spectrum Balanced；服务端另核对执行策略，包含 Attention、稀疏、模型和采样路径的冲突。
7. **已扫描的 H3 VAE 不可用。** 当前 VAE 选择无法解析为有效的文件和模式。
8. **已选 LoRA 的实际文件未匹配。** 扫描档案不可用，或者查到的是别的路径／文件，与选中的文件不一致。提交时也复验 LoRA 硬冲突。
9. **Spectrum 运行档位依赖不满足。** Balanced 已启用而扫描未确认节点加载，或者当前版本不满足启用的 Turbo、PDD 或模型感知子模式。具体门槛按所启用功能决定。
10. **Sage／Sage Triton 缺 KJNodes。** 达到该模式的实际依赖条件才允许提交；走其他 Attention 路径不检查这条。
11. **图片源无法归档。** 已选文件随后被移动、删除或不是文件；源／目标无法读写，复制失败、校验哈希变了，或目标已有同名冲突内容。覆盖首帧、尾帧、关键帧和 R2V 图片。
12. **多段的输出目录或 Run 存储根无法解析。** 例如输出路径未配置且无法解析实际目录，或目录不可访问／创建失败。
13. **任务快照或队列持久化失败。** 冻结时剧本、布局、媒体状态已经变化或数据损坏，构建快照时无法验证；本地状态存储或文件系统写入出错。

原生和多段都可能先完成提交，随后才在执行时发现更多问题，例如未扫描环境缺模型或节点、ComfyUI 无法启动或真实节点 schema 不匹配、上传／后端生成失败、资源不足。入队与启动 ComfyUI 是两个阶段。型号建议、H3 长时长的画质告警，以及 Strata 尚未增强都不是必须清除的入队条件。无扫描结果时主进程会把部分依赖检查留到执行准备。

Continuum 的「清空草稿」会清掉首尾帧、Add Guide、R2V 参考、全局提示词和各段稿，保留当前编辑模式和设置。点击清空后的通知可在 6 秒内撤销并恢复整份草稿。

本轮隔离 Electron 实测：两段手写纯文本任务 `61195786-50a1-4851-b705-ef99f1e1ba4a` 与仅尾帧任务 `e43a16b7-8360-41f8-9a4c-e987b8ac6afa` 均进入 waiting。未引用的空关键帧啟用可见提示，有效关键帧照常入队。通过真实鼠标清空并撤销，已核对原 Add Guide 路径和原剧本 ID 恢复。ComfyUI 保持 stopped。
