## 设计方向（提案，待 G1 确认）

定位：**“Darkroom”——暗房式创作工作站**。媒体是唯一高饱和内容，界面退到中性灰阶后面；用尺寸、留白、字重和表面阶梯表达层级，而不是用颜色和边框。

参考取舍（getdesign.md / awesome-design-md，2026-10-20）：

| 参考 | 借鉴 | 不借鉴 |
| --- | --- | --- |
| Linear | 4 级近黑表面阶梯、1px hairline、单一强调色、紧凑精确的字号表 | 营销页大标题 |
| Raycast | 无投影、用表面亮度表达深度；8px 按钮圆角、36px 控件高；焦点只提亮边框；keycap 快捷键样式 | 品牌红色条纹 |
| Runway | 作品为主角、masonry 不等比、“只有一个主按钮”，元信息退为小字 | 白色阅读底 |

- Inter（OFL）本地字体 + `Microsoft YaHei UI` 中文回退；数字用 `tabular-nums`。

### 规范草案（DESIGN.md 将细化）

- **色彩**：canvas → surface-1 → surface-2 → surface-3 四级；文字 4 级（ink/body/muted/faint）；hairline 2 级。强调色**只**用于主按钮、当前选中、进度与焦点；状态色只以小面积点/图标/文字出现，大面积底色仅用于错误阻断。
- **字体**：字号仅 `11/12/13/14/16/20/24`；字重仅 400/500/600；正文 13–14，元数据 12，最小 11；路径/ID 等宽且中间省略。
- **间距/圆角**：4 的倍数 `4/8/12/16/24/32/48`；圆角 `6`（chip/小按钮）`8`（控件/按钮）`12`（卡片）`16`（对话框/大媒体容器）`999`（pill）。控件高度 `28/32/36`。
- **层级**：每个区域最多一个主按钮；危险操作只用文字色而非实心；卡片不嵌套描边卡片，内部分组用间距和 hairline。
- **文案**：标题即说明；说明句默认不出现，只在空状态、错误恢复、首次使用时出现；技术细节进入“详情”折叠或 tooltip。
- **动效 token**：`--dur-1 90ms`（hover/press）`--dur-2 160ms`（显隐/颜色）`--dur-3 240ms`（面板/页面）`--dur-4 360ms`（大范围布局/列表重排）；`--ease-out cubic-bezier(.2,.8,.2,1)`、`--ease-in-out cubic-bezier(.4,0,.2,1)`、`--ease-spring`（拖拽落位，带轻微过冲）；全部受 `prefers-reduced-motion` 统一降级为淡入淡出。
- **手感**：hover 光感 = 指针跟随的径向高光（CSS 变量 `--mx/--my` + `radial-gradient`，透明度 ≤ 6%）+ hairline 提亮，只用于媒体卡、主卡和主按钮；按下 `scale(.98)`；拖拽抬起 `scale(1.02)` + 阴影 + 轻微透明，落位 spring；页面切换 160ms 淡入 + 4px 上移（View Transitions API，Electron Chromium 原生支持）；列表 enter/exit 与 FLIP 重排；封面先 `decode()` 再替换，消除刷新闪黑；数字补间（进度、遥测）。

## 用户决定（2026-10-20）

1. **黑白单色**：不用蓝色强调。白色主按钮，强调靠明度。画布不能纯黑、不能过深；灰阶从 Radix Gray/Sand/Slate/Mauve 与 Apple 系统灰中选择，推荐 Graphite 平衡（画布 `#191919`），备选 Sand 平衡。
2. **History 卡片**：现有信息保留，悬停自动播放保留；只优化版本数量。方案：单版本不显示；多版本用卡片顶部叠层边缘 + 元数据行小图标计数，不再占封面徽章。
3. **设置模型卡**：卡片保持展开；模型文件清单可折叠，摘要始终显示版本、显存、就绪数、节点安装情况与缺失项；展开后列出全部模型，下载面板内容和交互不变。重点是删减罗嗦的说明文字。
4. **原型**：旧原型归档到 `prototypes/legacy/`，在 `prototypes/` 重建。
5. **“未保存更改”是确认的 bug**（经常出现）。属于行为修复，单独处理；当前 `src/renderer/pages/settings/page.ts` 有他人未提交改动，等其完成后再修。
6. **长视频纳入设计**：[长视频编排 PLAN](../2026-10-18-long-video-director/PLAN.md) 的 UI 一并设计，先做原型样式。

第二轮反馈（2026-10-20）：

7. **背景更深**：默认深度改为“深”（画布 = 第 1 阶，Graphite `#111111`），另加“更深”档；不用纯黑。
8. **需要主题色**：黑白灰为主，增加一个主题色做自然引导。重要按钮更大、颜色突出。候选取自 Apple 系统色（暗色）：琥珀橙 `#ff9f0a`（推荐）、胭脂粉 `#ff375f`、靥紫 `#5e5ce6`、薄荷 `#63e6e2`、绿 `#30d158`、无（白）。按钮层级参考 Apple：突出 › 主要 › 着色 › 灰色 › 纯文字。
9. **边缘光**：卡片和按钮的边缘随鼠标亮起；同组内相邻元素的边缘也会被照亮。
10. **按钮加图标**：统一使用项目已有的 Lucide。
11. **下拉列表不换行**：列表宽度按内容伸展。
12. **数值用滑块**：保留原版“滑块 + 数字 + 单位”交互，不用 +/− 步进器。
13. **设置卡片保留全部操作**：模型卡、LoRA 卡、节点卡、运行时卡分别设计；“打开目录”会自动创建目录；下载在浏览器中进行（文件太大），用户自行复制到目标目录。
14. **组件覆盖要完整**：包括开关、快速插入、历史筛选与标签等。当前目录已覆盖的组件见 [prototypes/README.md](../../../prototypes/README.md)；尚未覆盖：视频播放器控制栏、Lightbox、图片标注/裁切工具、Upscale 对话框、图片资源库对话框、目录迁移对话框、日志页、ComfyUI 环境卡（多安装选择 / 服务启停）。

第三轮反馈（2026-10-20）：

15. **现有按钮全部有用**：现有每个按钮都是和用户反复讨论后留下的，不得删减或合并；具体页面排版在逐页原型里与用户逐项确认。目录中的“页面模式”只演示材质，不代表新的页面结构。

17. **筛选完整**：排序（最新/最早/评分高低/时长长短）、只看收藏、批量管理开关、评分区间、最短时长、模型、标签“包含 / 排除”两种状态、清除；结果数 `可见/总数` 显示在筛选按钮旁。
18. **悬停光只在边框**：取消卡片大面积背景光斑，只保留边框高光，文字和图标变亮。
19. **主题色改为蓝色系**（天空 / 海）：候选 天空 `#64d2ff`（Apple cyan，默认）、浅海 `#40c8e0`（Apple teal）、晴蓝 `#0090ff`（Radix blue 9）、海蓝 `#0a84ff`（Apple blue）；第 8 条的橙色等候选作废。
