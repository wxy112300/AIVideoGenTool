## 本轮处理

| 操作 | 确认的问题 | 处理 |
| --- | --- | --- |
| Create/Extend/图片参数、prompt输入后的草稿自动保存 | 即使返回void，仍完整复制历史用于回滚和持久化，并逐记录归一化/canonical | 新workspace窄事务，排除历史；历史复用已验证父提交，失败仍回滚；生产包装器转发，旧repository保留fallback |
| 外观开关、历史列数、普通设置保存 | 全库保存；外观保存还额外get完整状态一次 | 普通apply且无目录变化、appearance使用workspace事务；语言/默认值读取用getSettings；目录迁移仍完整事务 |
| 队列移动、拖动排序松手 | 为判定暂停分界和保存顺序复制整套历史 | 分界判定移入串行事务，workspace保存；任务配方、IDs、暂停分界和恢复行为保留 |
| 渲染期间周期性进度落盘 | 每秒flush仍处理历史正文 | 优先workspace无返回快照检查点，不替换live内存状态；节流、失败重试和旧flush fallback保留，补失败后新进度不回退的重试/重开测试 |
| 主题/普通状态变化比较 | structurallyEqual递归复制排序再JSON.stringify，可能扫描整个大状态 | 改为JSON形状直接比较，保留键顺序无关、数组顺序、undefined/空槽/非有限值的既有比较结果，补成对oracle回归 |
| NAS后台发布排队 | 相同待发布commit仍复制全库；调用方先为回调复制一次，即使无需发布 | needsSnapshot先看commit/输出根/语言，store预判后才生成回调快照；保留不同pending时撤回旧值、封面通知、失败重试和移动/退出flush |
