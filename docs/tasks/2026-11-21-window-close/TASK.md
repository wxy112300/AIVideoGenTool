# 关闭按钮响应与退出等待

- Status: done
- Impact: patch；不修改用户数据格式，不安装或重启生产 ComfyUI。
- Scope: 合并重复关闭请求、退出等待反馈与失败恢复、删除已确认无进程时的冗余扫描、限制中断/提示词释放等待。

## 已确认与实现

- 实际日志显示多次空闲关闭耗时约 10–26 秒，并在等待期间重复记录 Shutdown；一次连续重复八次。最近一次约 19 秒，ComfyUI 退出后仍有进程清理扫描。
- WindowShutdown 独立协调一次退出；LAN 与 runtime 清理并行，NAS 与 store 仍按安全顺序关闭。服务阶段成功后，存储失败重试不会再次停止服务。失败保留窗口，不丢弃未关闭的持久化操作。
- 原有任务/未保存设置确认保留，可在清理前取消；确认后显示服务/存储状态。清理开始后不再返回已部分释放的应用，失败只允许重试。确认弹窗的返回焦点在阶段刷新间保留。
- Comfy 初次进程与端口查询成功且未发现目标时直接返回；查询失败仍走复查，发现进程仍停止并验证。远程实例不终止。
- 普通中断与两个 worker 并行使用 15 秒等待预算；提示词释放与停止服务并行，服务检查结束后额外等待最多 2.5 秒；等待结束清除计时器。
