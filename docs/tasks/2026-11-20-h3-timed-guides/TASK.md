# H3 定时关键帧

范围为普通 FL2VA／R2V 单段生成以及新建 Continuum Full Run 的成片时间关键帧。

- 创建页的两种视图共享素材槽。普通模式显示首尾，关键帧模式显示全部。改时间或删除后，Picture 随显示顺序连续编号，提示词引用跟随原图片。旧尾图导入为跟随片尾。
- 入队归档图片并冻结关键帧快照。输入校验使用 H3 原生输出帧网格，禁止冲突或失效的编号引用。第 0 帧使用原生首图，其余按帧号串接 `MiniMaxH3AddGuide`。增强请求携带图片、编号和采样时刻。最终采样将 Studio 的 Picture 标签展开为关键帧位置描述。
- 关键帧快照从队列和 History 可回到草稿。普通首尾帧、文生视频及已有长视频仍走原有入口。
- 验收入口为 [Create 视频旅程](../../runbooks/PRODUCT_JOURNEYS.md#create-video)。定向测试覆盖缺输入恢复、排序、增强请求、冻结快照、H3 帧号与 Add Guide 接线。

## 创建页布局与 R2V

- 共享槽隔离验收：普通模式拖入首尾图，开启关键帧后加入第三图，改时间和删槽后编号与提示词同步。关掉模式后替换尾图，再打开即可看到同一素材。使用真实按钮入队，冻结的 Picture 1 为 0.5 秒，Picture 2 为片尾。重启后核对素材槽、首尾字段与队列 ID 均恢复。测试应用和端口均已退出。
- 共享槽相关单测、132 项集成测试、renderer 构建、Electron 编译及 440 项对比度检查通过。全量单测 3342 项通过，4 项受 Windows 超时或文件锁影响。
- FL2VA 与 R2V 共用标题右侧的设置开关样式。FL2VA 使用原首尾帧预览尺寸，秒数叠在预览上。R2V 在原有图片卡片标题行增加可选时间。
- FL2VA 秒数沿用分辨率标签样式，在右上角与实际图片尺寸并排。右下角沿用原「替换」「清空」操作条。清空保留 Picture 槽位及其秒数，删除槽位使用 Picture 旁的独立按钮。
- 隔离 Electron 验证 1560 像素与 480 像素下秒数、分辨率和操作条互不遮挡，开关前后原图尺寸一致。输入 0.5 后直接点击清空，分辨率隐藏，槽位保留该时间。重新拖入后恢复实际分辨率，通过真实按钮入队并冻结秒数。窗口与测试监听均已退出。
- 分辨率与操作条修正后的全量 `verify` 通过，包括 3344 项单测、132 项集成测试、生产构建和 440 项对比度检查。
- R2V 保留角色、备注、图片顺序和 Picture 引用。增强把时间与原 Picture 关联，入队冻结已填写的时间。生成图复用 R2V 已加载的参考图片，从第 0 帧起通过 Add Guide 写入采样条件。
- 从 R2V 队列或历史返回创建页时，按任务中冻结的 Picture 编号与秒数恢复原有参考卡片。使用本机 ComfyUI 只读接口核对 `MiniMaxH3ReferenceToVideo` 与 `MiniMaxH3AddGuide` 的输入输出。
- 隔离 Electron 实测 R2V 缺图到补图、设为 0.5 秒并点击入队。在草稿关闭关键帧开关后，从队列编辑该任务，开关和 0.5 秒按快照恢复。测试窗口与端口已经退出。提交层回归通过模拟 HTTP 接收端检查了实际请求体，0.5 秒解析为第 12 帧，Add Guide 使用原 Picture 的图片节点，普通参考图无需重复上传。实机采样未执行，验收时可用系统内存约 2.7 GiB。
- R2V 最终定向回归 36 项通过，生产构建及 440 项对比度检查通过。全量回归期间环境和断点续传各有一项 Windows 超时。
- 隔离 Electron 验证了 FL2VA 切换前后预览尺寸相同。R2V 在 1560 像素宽度下时间输入与卡片操作同排，480 像素下无横向溢出。实际拖图、时间越界恢复并点击加入队列，快照中的 Picture 1 为 0.5 秒，使用与 R2V 参考图相同的归档路径。重启验证开关、秒数与队列快照均已恢复。测试 Electron 进程和监听已退出，未启动 ComfyUI 采样。
- 46 项定向测试、132 项集成测试、类型检查、生产构建及 440 项对比度检查通过。全量单测限并发重跑，3343 项通过，`tests/environment.test.ts` 的子进程终止测试达到 5 秒超时，单独重跑仍超时。R2V 成片待实机验收。

## Continuum

- FL2VA 普通首尾图接入原生首尾帧，忽略切回 FL2VA 后隐藏的 R2V 槽。R2V INT8／INT4 使用 Continuum 原生图片参考位 1–9。填了时间的图片同时进入现有全局时间 Guide，提示词和增强保留 Picture 编号。视频参考仍走单段原生 R2V。
- 隔离 Electron 验证 10 秒两段的 R2V 5.2 秒引导入队，切回 FL2VA 后带首尾图入队且草稿仍保留 R2V 槽。应用启动的隔离 ComfyUI 使用原版 Continuum 及项目 H3 节点 0.4.4，三种模型的 API 图通过真实 schema 校验。旧应用节点缺少定时 Guide，界面提示在设置更新。未启动 GPU 生成。测试 Electron 与 ComfyUI 已退出。
- 80 项定向测试及 132 项集成测试通过。全量单测有环境超时和现有 LoRA 目录清单断言差异。

- UI 秒数以成片的 24fps 时间轴为准。普通 10 秒 2 段样例的实际第一组保留到第 123 帧，第 124 帧进入第二组的局部第 22 帧。第 239 帧对应第二组局部第 137 帧。位置由上游当前组实际保留范围决定。显示尾补帧时没有独立采样帧的标记会给出错误。
- 上游包文件保持原样。应用 H3 节点 0.4.4 的多图适配只处理应用标记的 bundle，复用 Continuum 的预处理、逐组位置解析、conditioning 注入及组装计划。所有图片内容和绝对帧进入官方 Guide contract，旧快照没有相关字段时沿用现有路径。
- 长视频分配情节和扩写把全部有效关键帧图交给本机 Strata，附稳定 Picture 编号及成片和段内时间。重复引用同一图片时共用一个附件，保留各个落点。普通长视频首图沿用原请求路径。
- 多图增强定向验证共 70 项通过，覆盖真实创建页控件、合成图片字节进入 Strata 请求、切换到其他后端时拒绝请求。类型检查通过。机器空闲物理内存约 4.3 GiB，本轮验收使用合成模型响应。
- 已使用已安装的上游实现完成 CPU 接缝解析和采样条件挂载检查。新增 Python 定向测试检查跨接缝、原单图、包内所有图的 refine metadata 及越界。
- 独立 Electron 实际拖三张图，完成缺输入到可点击入队。实际 ComfyUI 0.45.0 中，同一个官方 Full Run 收到绝对帧 123、124、239，并执行视频 VAE；H3 文本编码日志出现后，等待窗口内无成片。另用官方组装器、合成帧及磁盘缓冲在 CPU 上得到 240 帧和 10 秒音轨，三处标记在合并后仍落在 123、124、239。
