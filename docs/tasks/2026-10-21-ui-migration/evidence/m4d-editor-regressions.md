# M4d：创建页回归、自定义分辨率与富文本

2026-10-22。minor；当前 agent 直接完成。用户要求恢复自定义分辨率、改用清空撤销通知并正式接入富文本，取代 M0 对 B6/B8 的暂缓范围。

## 处理与边界

- 时间与运动：原生刻度 1/5/10/15.1，解锁刻度 1/10/20/30，最大值仍以实际模型安全预算为准；短时长下重绘不会把解锁模式切回原生。长视频演示刻度保留 4/30/60/90/120。
- 自定义：恢复图标入口、滑块、数字框与两端刻度，输出宽高实时更新。标准 H3 由 catalog 声明短边 256–768、步进 16；Q3 等受限配置吸附到自身支持档位。沿用 resolution 数字字段；UI、恢复历史源尺寸、入队安全检查与图构建接受同一范围。1080p 专用两阶段路线不通过自定义选择。
- 清空：视频/续写和图片立即清空，六秒通知允许恢复完整草稿，包括素材、版本、Seed 与参数。已清空时重复点击不覆盖原撤销；各次清空通知独立，悬停/键盘焦点暂停生命周期。长视频演示有独立本地撤销，不写真实草稿。
- 图标：视频 Seed 随机按钮使用原型的 dices。
- 富文本：对照 `prototypes/create.html` 与 `prototypes/app/create.{js,css}` 实现参考缩略标签、缺失提示、时间标记、对白与字段高亮；编辑区 132–320px、12×14px 内边距、1.85 行高、22px 引用标签。视频、图片及长视频分页输入共用适配器；原 textarea 是控制器纯文本边界，不保存 HTML。
- 编辑保护：自管 Ctrl+Z/Ctrl+Y/Ctrl+Shift+Z 历史，保留原提示词版本清空事务；粘贴只取纯文本、复制引用还原标签、引用整块删除。连续回车/Shift+Enter 直接插入换行字符。长视频各页历史隔离，锁定页不可撤销改写。
- 刷新保护：清理旧富文本时把焦点与选区交给源控件，再由 render coordinator 恢复至新编辑器。RendererApp 在清理前检查组字状态，确认输入后再刷新；不能只在 DOM 替换前等待。
