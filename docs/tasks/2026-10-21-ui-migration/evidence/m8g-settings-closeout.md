# M8 收尾

日期：2026-10-24。影响：minor。M8a–M8f 的设置页迁移在本批补齐并关闭；下一阶段为 M9 全局收尾。

## 本批修正

- 保存条按实际 changed keys 显示字段名，不依赖当前分区的 DOM；跨分区编辑保留摘要，改回原值移除对应变化。只展示名称，不展示路径、地址或其他设置值；外观即时保存仍不计入未保存事务。
- 对照原型补齐创造性滑块和数值框，范围 0–1.5、步进 0.1，支持 0.4/0.8/1.3 等中间值；读写仍沿用 `promptCreativity`。滑块、输入、填充和保存条局部同步，不请求页面重绘；空值/越界输入在结束编辑时恢复有效值。既有超出原型范围的保存值扩大控件边界，避免浏览时截断。
- 思考强度改为分段选择，保留真实 Strata 的 off/low/medium/high 四档及原生 select 数据源；非 Strata 页面仍隐藏这项控制。
- 18 个无提示词起稿方向的三语说明改为短句，完整可编辑生成指令保持不变。删除重复连接说明和正常状态下的 Attention/VAE 技术描述，精简安全取消、自动重试及强制停止文案；错误、禁用原因和停止全部实例的后果保持可见。
- 修正提示词分区标题与卡片标题重复、滑块桌面宽度，以及窄屏模型选择器被高优先级旧宽度规则覆盖的问题。
