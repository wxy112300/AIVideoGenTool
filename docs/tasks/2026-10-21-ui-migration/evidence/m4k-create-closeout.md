# M4k：创建页收尾

日期：2026-10-23。影响：patch；M4 整体迁移仍按原计划归为 minor。

## 结果与修正

M4 按当前真实模型能力及 B20 的本地演示边界关闭，下一阶段为 M5 Queue。本轮不重做已验页面包，结合 M4a–j 的原型尺寸、动画、素材、裁剪、编辑器和续写证据完成整页回归。

- 图片模型名称、质量/比例选项、LoRA、Mask 操作、标记默认文字和相关状态使用当前语言。核心选项值、持久化字段及工作流语义不变；仅在 renderer 翻译旧选项标签。
- Qwen 2.1 等支持文生图的空参考区显示“可选”，必需参考图的模型继续保留原门槛。
- 图片提示词输入后使用当前语言计数，避免英文初始界面在输入后切回中文计数。文档 `lang` 随恢复/切换的设置同步。
- 原有用户标记文字、后台原始诊断与未知自定义选项不批量改写；不声称任意服务错误都已翻译。
