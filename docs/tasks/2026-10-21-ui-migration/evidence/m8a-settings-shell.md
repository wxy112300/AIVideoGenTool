- 对照 `prototypes/settings.html`、`app/settings.css`、`app/app.css` 与设计系统 `surfaces.css`：220px 侧导航、34px 项高、2px 间隔、无外框背景，原型分区顺序和图标，窄屏按可用宽度换行。新增独立 `src/styles/pages/settings.css`；标题精简并吸顶，真实 GPU 信息保留。
- 保存/放弃移到底部居中条，只在有改动/保存时显示；实际变更项数来自共用纯函数 `settingsChangedKeys`，排除即时持久化的 appearance。输入时只更新计数/显隐，不重建表单；Ctrl+S 调用同一个有效保存按钮。沿用既有离开确认。
- 首次扫描后的自动 ComfyUI/Python 路径之前由 UI 显示值直接回写空配置，造成误报。现在与自动输出目录一样标记自动值并保留其原意；真正改选路径仍读取。快速回归另发现扫描前空模型 select 会回写空值，已保留无选项时的原保存值；明确选择空选项的控制仍能清空。
- 实测发现底部条继承旧 `save-state` 黄色胶囊和伪元素，已在本页清除，保留单一主题色状态点与文本。保存条 z-index 65，低于菜单/对话框，遵守实际图层合同。
