日期：2026-10-23。影响：minor。现有队列页面包完成；创作包扩展受 B13 和长视频 TASK 能力边界约束。

## 接入与原型

恢复迁移 TASK、设计决定第 34/40/41 条，阅读队列原型 HTML/CSS/交互及当前卡片、控制器、实时补丁、预览、排序和确认路径；使用项目 Skill 与 harness:app -- guide create-video 验证真实创建入队。

- 页头收为标题及一行状态，保留实时预览、开始/结束/继续和启动/清理/错误反馈；未开始不显示计时占位。
- 四格性能条保留用量/温度，数值 16px、轨道 3px，高占用使用警告色，数字与进度在原节点补间。
- 等待/需处理卡使用把手、队位、88px 方形缩略图（窄屏 72px）、正文和操作排列。标题与把手对齐，常规等待不重复贴状态；失败、取消、重试、延后执行和错误保持可见。
- 运行预览安全区宽 160–260px、高不超过 220px，媒体完整显示；右侧标题、进度/20px 百分比、阶段/工作量/时间、提示词、贴底参数。保留 SeedVR2 独立分片进度及检查点恢复。
- 提示词默认两行，按空间最多 12 行，溢出才显示展开；展开在 260px 内滚动并完整复制。仅对执行提示词估算 tokens，放大任务文件名摘要不冒充提示词。
- 移除收进菜单末尾的危险项，沿用原确认；其余菜单方法和资格保留。卡片/分割线改为列表内绝对定位、仅纵向移动并约束范围，修正容器查询下的横向漂移；点击把手明确聚焦以便 Home/End 排序。

删除被替代的 legacy 队列 CSS，新页面样式位于 pages/queue.css，没有追加 override 层。图片选项翻译适配器移到 renderer shared，创建与队列共用；未改 core 选项值、IPC、持久化字段或工作流。

同视口人工抽查原型和实际宽屏运行/等待、长提示词、窄屏、150% 英文缩放、图片/续写/放大。布局参数按原型对齐，真实媒体/错误和缺失能力保留生产差异；截图采集不等同于逐张像素人工审计。

## 边界与资源

现有服务在暂停时把 deferred 任务移到分割线上方会恢复执行。本轮确认并保留此语义；一次隔离检查因此进入 queue running，ComfyUI 未连接，随后经 AppApi 暂停/取消并清理。正式无生成排序检查先清除分割线，不把运行状态当 GPU 成片证据。

tokens 复用现有文本估算器，提示明确不含图像和模型附加内容；没有新增真实 tokenizer。各模型执行参数、旧队列/检查点身份保持不变。
