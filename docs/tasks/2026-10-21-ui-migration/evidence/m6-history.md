## 实现与保留

- 卡片按原型使用单行徽章与两行文字；视频不再显示版本数，图片仅多版本时显示。完整模型名、标题及文件名仍可通过悬停和菜单查看。保留真实尺寸、模型差异、图片迭代标记、收藏/评分、悬停播放和预览定位。
- 列表沿用容器驱动的瀑布流/相册算法与媒体调度。瀑布流间距 10px，相册 8px；820px 页头边距改为读取外壳 gutter，避免 8px 横向溢出。
- 页头只切换筛选栏，结果数并入标题；筛选和批量操作共用吸顶卡片。模型多选、评分双滑块、时长分档滑块及标签逐项包含/排除按最终原型接入。
- 筛选区 DOM 在条件变化、环境扫描等同类型/同语言刷新时保留；窗口搜索、滚动、焦点与行顺序不丢失，新 facet 追加。类型/语言变化正常重建。滑块拖动先更新反馈、释放再刷新结果。修复移除/切换标签时的焦点丢失；Esc 恢复触发按钮焦点。
- `modelIds` 为规范筛选字段；未提供数组时读取旧 `modelId`，显式空数组表示全部。LAN 新 URL/响应使用新形状，旧查询仍可归一化。没有新增桌面筛选持久化，也没有迁移历史/队列身份。
- 图片忽略视频专用时长与时长排序，保留视频原选择。排序/布局/宽度重排保留批量选择；其余筛选条件改变时沿用既有清空选择语义。
- 批量标签使用原生居中 modal，修改立即保存，包含共同标签、部分已有计数、补齐/移除及输入建议；完成、关闭、Esc 和焦点返回可达。批量删除保留关联引用二次确认，补齐类型/数量、标题、最多六张缩略图与带数量的删除按钮。
- 时间轴不占画廊列宽；仅时间排序且内容可滚动时显示。静止细轨道，滚动/悬停/拖动显示日期、数量与月份；实现按天箭头、按月 PageUp/PageDown、Home/End。修复拖动后的键盘焦点，并使主动滚动/按键取消尚未完成的详情返回位置校正，避免回弹。
- 封面在独立 Image 完成 `decode()` 后替换现有呈现；中止/失败保留旧图。首次进入与视频/图片切换错峰呈现，减少动态效果走淡入，媒体调度/缓存和离屏控制继续沿用。
