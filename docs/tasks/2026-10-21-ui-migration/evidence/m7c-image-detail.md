## 完成范围

- 版本缩略栏、窗口高度驱动的图片画面、版本位置与前后按钮；画面支持点击或 Enter/Space 打开大图。
- 扁平右栏按作品/信息/创作/文件/版本/删除分区，评分收藏、复制图片/文件、定位、继续编辑与图生视频保留实际入口。自动封面的当前版本禁用重复设置，手动封面仍能恢复自动。
- 本次编辑要求独占全宽；来源、生成信息、输入图片、输出文件和已有运行统计进入高度平衡的固定双列，窄屏恢复源顺序。原图隐藏编辑要求、生成参数和输入图片，保留原图删除保护。
- 输入预览按可见性读取保存的标记图/裁剪图/原图，不伪造标记形状；显示实际裁剪、Canvas 标记与 Mask 状态。相同路径合并读取，离页后忽略迟到结果，缺失时沿用媒体状态与定位恢复入口。
- 文件区为 42px 紧凑行，路径与身份保留，输出 JSON 默认折叠。生成快照继续保留模型、质量、LoRA、尺寸、Seed、工作流及 Prompt ID；无记录值不冒充有效参数。保留 Qwen/MOSS 等实际模型差异。
- Lightbox 改为满窗口黑底与紧凑顶栏；保留滚轮指针中心缩放、放大拖动、0/双击复位、方向键切版、Esc、焦点恢复与背景 inert/滚动锁定。补齐空白处关闭；切版不重建大图节点，关闭后详情与回流动作同步到所选版本。英文长创作按钮允许内部换行。

## 实跑发现并修复
