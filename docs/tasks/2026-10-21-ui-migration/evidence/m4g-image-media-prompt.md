# M4g：图片素材与提示词卡首批

2026-10-22。Minor，沿用当前工作区及全部图片 capability，不冻结 FastH3/MOSS 等增量。无子 agent、版本号变动、提交或打包。

## 交付范围

本批按既有用户授权迁移图片素材区和提示词卡，不把整个图片页标为完成。

- 素材从旧横向缩略卡改为纵向 Slot 卡。顶部为编号、Picture、基础输入、文件名及现有标记/Mask/删除工具；图片保留原比例，竖图限制 640px 高。素材区无可见滚动条，保留滚动和拖放/粘贴入口。
- 裁剪、标记数和 Mask 放在素材角标；替换和清空在悬浮操作条，键盘进入时同样显示。托管入库后优先展示原文件名，完整当前路径仍在 title。
- 新增清空素材操作，只移除内容、尺寸、crop/markup/mask 和旧 contentHash/托管路径身份，保留 Slot ID、编号、参考作用与提示词引用。删除 Slot 继续沿用已有重编号和引用修正逻辑；基础位原有保护不变。
- 图片提示词独立成卡，保留富文本纯字符串边界、版本/撤销、模型释放与提示词优化。计数移至底部；快捷插入复用视频页的搜索菜单，支持过滤、无结果、连续点击和 Escape；隐藏 select/button 继续作为既有控制器边界。
- 无图模型、单图抠图、LaMa promptless/Mask、模型参考图数限制仍由当前 capability 决定；没有照搬原型虚构运行能力。

参考：设计 TASK 的用户决定 22、39，以及 `prototypes/app/create.js` 的 renderPictures 和 `prototypes/app/create.css`。独立隐藏 Electron 加载原型并完成动画后取样：卡片 padding 10px、gap 10px、标题行 28px、编号 20px。生产窗口相同指标一致；提示词工具栏去掉旧 44px 最小高度，改为 28px。原型未改动、未重建。素材示例比例与实图不同，不声称整页像素完全一致。
