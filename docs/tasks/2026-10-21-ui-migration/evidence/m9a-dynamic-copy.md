## 发现与修正

1. 部分分段选项没有 id，选中项记忆一直为空，导致 History 布局、放大倍率、思考档位等底块不播放切换动画。现在使用组内稳定位置识别无 id 选项；快速反向切换从当前动画位置衔接，同值刷新不重播。
2. 普通刷新也会 skip 正在播放的页面转场。现在只有下一次页面导航跳过旧转场；参数、遥测和进度刷新不提前截断转场。
3. 创建模式和设置分区缺少分块入场。现在仅在模式/分区真正改变时播放 240ms 淡入与 6px 上移，间隔 30ms、最多六级；不重播同页参数刷新，不动画化吸底提交条。减少动态时改为无错峰的 120ms 淡入。
4. 系统偏好与手动减少动态的 CSS 策略不一致，且历史卡片仍自动悬停播放。现在系统跟随与手动减少均关闭循环、位移和扫光，只保留 120ms 颜色/透明度过渡，hover 即时；强制标准可覆盖系统减少偏好。开启减少动态会停止已经启动的卡片自动预览，但不影响详情页主动播放。Lightbox 的减少动态时长也统一到 120ms。
5. 自定义下拉在无关刷新时重写相同标签、重建已打开选项。现在标签/状态值不变就不写 DOM，菜单内容不变就保留选项节点和用户滚动位置；真正改变选项、说明或禁用状态仍同步。
6. 文案遗漏：三语精简 14 组检查/工具提示/放大状态；21 个节点用途使用简短的当前语言文案，未知节点保留后端用途。Strata 卡去掉算法与分片大小长段，三个放大模型去掉实现流程说明。设置模型卡从当前语言 catalog 取描述，修正扫描缓存语言滞后，并删除重复的后端说明；图片模型卡复用创建菜单的能力说明，保留文生图、参考图数量、蒙版与抠图区别。模型文件、硬件要求、LoRA 兼容/触发词和缺依赖恢复入口保留。

收尾真实截图还发现硬件信息重复、通用推荐与具体模型要求不一致。现在优先展示模型自己的资源要求，缺失时才用既有推荐；LoRA 不再重复基础模型的通用硬件推荐。最终三语实测 `accepted-copy-report.json` 验证每张卡只有一行资源信息，截图 `accepted-<locale>-image.png` 优先于早一轮 `copy-real-*`。

## 动态实测

真实生产 Electron，物理隔离媒体与 userData，CDP 原生鼠标/键盘；开启 focus emulation，1440×1000，标准动态模式。没有改 disabled 或直接调用提交 handler。

- 随机/清空 Seed、720p/自定义切换、原生拖动时长和放大目标切换：每条约 1.4 秒连续 rAF 采样；富文本和 Seed 原节点保持，滚动差为 0，同时点亮控件最多 1 个，没有全页边框/阴影过渡。实际 DOM 会更新局部文本/状态，不能把非零 MutationObserver 计数描述为“完全没有重绘”。报告 `dynamic-report.json`。
- 六条采样的帧间隔 P95 约 16.8–16.9ms，最大约 16.9ms；这是本机隔离窗口的有限操作结果，不推广为任意历史规模、GPU 负载或所有机器的帧率保证。
- 实际切换创建模式捕获入场中间态，实际切换放大目标捕获 `::before` 的 transform/width 动画；系统跟随、强制标准、手动减少三种偏好分别检查。标准模式历史悬停预览启动，切换减少动态后停止。
- 菜单保持打开 2.1 秒，选项、触发器和 SVG 保持原节点；七次快速导航最终落到最后选择的页面，图标均已解析。设置分区有入场动画，只浏览不出现未保存；原生队列拖动保持列表 X 坐标，Esc 取消后队列快照相等。报告 `navigation-report.json`。
- 创建页空提示词阻塞 → 原生输入恢复 → 实际按钮入队 `f185ca0e-06ae-422b-80a4-b1b865a58392`；队列始终暂停，后续改 Seed/提示词不改变该任务或之前任务。报告 `create-report.json`。

安装过程另外采用当前生产 renderer 的呈现夹具：环形进度与扫光连续四帧变化、按钮宽度不变；五个安装阶段呈现；系统跟随/强制标准/手动减少策略一致。报告 `install-motion-report.json`。它不代表真实安装或 subprocess 验收，本次没有修改用户环境。
