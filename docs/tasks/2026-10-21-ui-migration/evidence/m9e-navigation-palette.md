# 历史转场与遗留配色回归

日期：2026-10-25。范围：patch，保留当前布局、页面能力及数据契约。

后续用户实测仍发现顶栏被快照遮住：本轮只核对 DOM 坐标/关键帧，不能证明实际合成画面可见。下面的“独立快照”方案由 M9f 的真实内容淡入替换；历史锚点/预留高度及配色修正保留。当前验收见 [M9f](m9f-shell-visibility.md)。

## 定位与修改

- 实际 Electron 的 View Transition 动画记录显示，共用 `app-page` 的组动画从 `translate(32px,72px)` 插值到 `translate(32px,-1728px)`，同时改变主内容高度。这是深处历史返回时大幅飞动/拉伸的直接来源。
- 每个路由改用独立名称，关闭组的位置/尺寸动画，主内容只淡出/淡入。根和顶栏继续不参与快照；快照层不截获鼠标。历史标题、媒体导航和筛选容器独立捕获，不参与列表的淡入或位移。
- 普通目的页在快照回调内归零滚动；历史页同步恢复并校正素材锚点。异步尺寸补偿及用户滚轮中断恢复仍保留。复用原列表时先接回 DOM，再绑定固定栏尺寸观察；筛选栏用实际标题高度定位，适应窄屏两行导航。
- 真实尺寸检查又发现离屏卡片文字区的占位测量会返回 125px，实际两行文字区为 47px。固定该文字区高度，并读取 CSS 高度作瀑布流/相册预留，避免新建列表后每列再大幅排布。
- 截图里的续写空素材区仍继承旧蓝灰渐变。改用 surface/line 令牌，悬停和拖入使用 accent。并清理实际页面检查发现的图片素材空态/编号、面板边框、服务状态、滚动条、Python 选择容器、缓存进度等旧配色。没有把媒体内容本身的颜色或具有语义的状态色统一改灰。

## 验证

- 完整 `npm.cmd run verify`：2536 单元、91 集成、typechecked build、440 对比度检查通过。新增用例验证快照前目的页滚动、窄屏固定栏实际尺寸，以及第一帧之前的锚点校正；原有滚轮取消补偿用例保留。
- 真实 Electron，隔离 36 个视频/10 个图片作品夹具，启用 focus emulation。1280×900、700×900 各从创建/队列/设置返回历史 1800px，共六组。顶栏始终 top=0；历史标题 top 分别为 72/93px，筛选容器 top 为 136/199px，全程不随列表移动。
- 记录浏览器实际伪元素动画：只有旧/新路由 opacity 关键帧，没有 group 的 transform/width/height 插值。捕获首帧与动画结束后的素材中心误差小于 1px。中间活 DOM 的 content-visibility 尺寸校正不等于可见快照的位移，二者分别记录；不把后台 rAF 间隔当作显示 FPS。
- 详情返回同一素材中心 694.43→694.37px，未靠绝对 scrollY 判断（内容高度校正可改变 scrollY）。20 次、45ms 间隔的实际鼠标导航后正确停在单个历史列表；减少动态路径没有位移/尺寸动画。
- 续写空态计算背景为中性 rgb(25,25,25)，background-image=none、边框 rgb(58,58,58)，人工复查宽/窄截图。普通创建三种模式、设置环境、队列和历史的实际计算样式检查用于识别旧蓝灰残留。

本轮不启动 ComfyUI/GPU。自有 Electron 窗口退出，测试端口清理，隔离 state 按原字节恢复。上千条全量历史重建仍有 M9d 记录的长任务，虚拟列表仍是独立待办；本轮只关闭转场几何/返回锚点问题，不扩展为大量记录的性能完成声明。
