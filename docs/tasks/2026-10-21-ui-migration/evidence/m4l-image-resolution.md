# M4l：图片自由尺寸回归

日期：2026-10-23。影响：minor。用户明确纠正图片 slider 应自由取值，快捷项不能作为尺寸白名单；本轮授权取代 B7 此前延期边界。

## 修正

问题同时存在于两层：renderer 把滑块/数字输入吸附到固定值，core normalize 又把中间值退回 source。现在原图/默认与旧快捷项保留，增加与视频一致的“自定义”入口；自定义滑块/数字输入在 480–2160 请求短边范围内按当前模型网格取值，不跳回快捷项。

普通画布用 8px，MOSS 16px，Qwen 参考编辑 32px；实际输出继续遵循原有模型尺寸计算和快捷项舍入规则，界面显示真实输出尺寸。原图输出和仅支持原尺寸的工具不被放开。数字输入越界被约束到范围；滑块圆点、填充、数字、选中底块和底部摘要一起更新。

ImageTargetResolution 从固定数字联合改为 source 或 number，但持久化形状、字段、IPC 和任务身份不变。归一化接受范围内整数，草稿恢复/队列构造保留中间值，旧队列已经冻结的 outputWidth/outputHeight 不重写。自定义模式是本地 UI 状态，非快捷值重开时自动进入自定义，没有新增持久化模式字段。
