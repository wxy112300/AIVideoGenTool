# M8e：模型与 LoRA 目录卡片

2026-10-24，direct，minor。接续 M8d 后的用户“继续”，本批处理模型目录和相关来源入口，不关闭整个 M8。

## 对照与实现

- 读取 `prototypes/settings.html`、`prototypes/app/settings.js` 的 `modelCard`/`loraCard`/`compRow` 及分组逻辑，按同视口截取视频、LoRA、图片、提示词、放大页。卡片结构跟原型；内容与可用性使用当前扫描和 catalog，包含 FastH3/MOSS 等实际增量，不复制原型中的版本、数量或模型选项。
- 五类目录共用紧凑概览、单行用途、资源策略/硬件与状态。一般模型的文件列表默认折叠，显示实际找到文件数与缺失必需组数；必需替代组与可选文件仍由现有 `modelComponentSatisfied`/missing count 判断，不把可选文件当作必需缺失。
- 缺节点、缺运行组件和明确的产品锁定原因在折叠区之外完整显示，不能因折叠文件而隐藏恢复所需信息。文件完整、节点静态检查、运行验证和待集成仍使用现有 evidence 语义。
- 文件行按原型分名称/标签/来源与路径两行；缺失文件使用带文字的下载按钮，已找到文件使用信息图标进入原有来源窗口。保留 profile ID、component index、所有现有安装指南与目录操作。CircleDashed 已注册，真实缺失状态无未渲染图标。
- 共用标记只对多个 profile 扫描到的同一路径显示，归一化 Windows 斜线和大小写；独立 Strata 根不参与相对路径共用推断。没有增加持久化字段或复制文件目录来源。
- LoRA 分组来自适配器的 `modelFamily` 与 `compatibleModelIds`，以 H3、H3 R2V、图片组顺序展示；未来未知项保留。两列独立卡片在窄屏切一列，使用说明位于文件行下方；修复旧伪元素造成的重复箭头。
- 原生 details 与高度/箭头过渡负责展开。UI-only WeakMap 保存每个 profile 的展开状态，扫描/重绘不写入 settings，未保存参数和队列不受影响。
- 视频/图片/放大默认模型卡改成横向行，Prompt 首张本地模型卡收紧；所有原生字段 ID、选择项、禁用门槛、运行按钮与设置读取链保留。图片质量档仍按实际模型提供选项，不固定成原型的两个示意值。
- 来源窗口收紧为标签/值行；已安装文件显示找到的路径和“查看来源”，不再显示重新下载指令；缺失文件保留下载页、目标目录及必要指南。文件来源、revision、SHA-256 和目录仍来自现有 installGuide/scan，不伪造扫描或下载成功。
