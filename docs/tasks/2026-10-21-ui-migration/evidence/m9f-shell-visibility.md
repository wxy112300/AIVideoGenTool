# 顶栏遮挡与四页标题位置复核

日期：2026-10-25，patch。承接用户对 M9e 的实际截图反馈。

## 原因与修正

上一轮验证只证明 DOM 坐标不动，没有证明合成后的顶栏可见。原生 View Transition 的伪元素覆盖层绘制在普通页面之上，独立列表快照仍可能越过真实顶栏；提高普通 z-index 无法解决这一层级关系。

- 删除路由原生快照及对应 CSS，改为真实内容区 160ms 淡入（减少动态为 120ms）。顶栏、页面标题、媒体导航和筛选容器不隐藏、不淡入、不进入动画祖先。
- 历史滚动和锚点校正在列表隐藏期间完成，再显示列表；普通参数/遥测刷新不触发路由入场。
- 四个主页面共用标题几何。消除原有主内容顶部 16px 差异，统一最小 56px、标题 20px/28px 及页边距；保留详情页原有内容间距。
- 队列标题状态改为同行排列，保留状态和操作。窄屏显式取消继承的 flex 列方向，避免队列标题居中；历史首行明确至少 36px，修正两行导航时的 1px 基线差异。
