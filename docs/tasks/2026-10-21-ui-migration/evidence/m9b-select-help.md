## 发现与修正

此前没有完全解决：共享 select 将原生 `title` 转发到触发器，Settings 还会在选项改变时把当前说明重新写入 select.title。统一 tooltip 接管后，这些内容就会在整个下拉框上弹出，和已有的字段图标/选项副标题重复。

- 共享下拉不再转发这种 title。字段含义由已有 ⓘ 承接，选项说明继续在菜单中渲染为副标题；保留旧 option.title 的副标题兼容，不影响旧预设数据。
- 创建页步数说明移入字段旁的 ⓘ；Spectrum 使用已有图标，不重复新增。增量刷新同时更新帮助文本与可访问名称，不替换富文本或原生 select。
- 设置的 Attention、稀疏模式、运行策略、VAE、编译器去掉重复 select.title；保留字段帮助、选项说明及选中项的读屏描述，移除控制器重新写回 title 的路径。
- 视频预设、起稿方向、图片预设的选项介绍归入展开菜单，删除选中项在左侧重复的常驻介绍。预设规则编辑区、原有参数与保存语义保持。
- 自定义 select 的可访问名称不再混入 label 内信息图标的整段说明。没有对所有 tooltip 做全局屏蔽，文件路径、图标按钮等必要提示保留。
