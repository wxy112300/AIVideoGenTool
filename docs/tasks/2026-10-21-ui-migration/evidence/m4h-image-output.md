## 对照与交付

参照 `prototypes/create.html` 的 image-model、image-res、count-field、LoRA 与 submit-bar，以及 `prototypes/app/create.css`、`create.js`。读取设计 TASK 用户决定 22、39；复用 M4g 原型截图作为布局对照，不修改原型。

- 输出卡标题独立，去掉常驻批量生成解释；模型占两列、质量在右，比例与 Seed 同行，尺寸和数量各占整行。窄屏沿用已有响应式列数，不制造横向溢出。
- 模型菜单按当前 catalog/capability 分为“生成 / 编辑”和“工具”，选项下显示真实本地化说明；保留当前扫描禁用状态和现有全部活动模型，包括原型没有的 MOSS 等增量。
- Seed 改骰子图标；比例、尺寸、Seed、数量、LoRA 强度局部同步，不重建提示词或素材节点。模型/质量/LoRA 结构变化仍按原控制器更新，不扩大后台能力。
- 分辨率为原图、720、1024、1080、1536、2160 升序快捷行、尺寸读数、滑块和数字框。全部现有固定档位均可达，包括快捷行以外的 480/640/768/1152；数字输入吸附最近合法档位。滑块按尺寸比例定位，显式指针捕获和方向键遍历，填充遵循公共圆点中心行程计算。
- 数量滑块配刻度、数字框和单位；提交条同步模型、数量和输出尺寸，使用原型的大按钮、list-plus 图标及稳定标签宽度。
- LoRA 复用搜索添加菜单，紧凑显示名称、族、说明入口、强度及移除；文件缺失仍是可见错误。只列出扫描可添加或已选中的兼容项，保留默认 Prompt 和 BFS 等输入要求。选中状态与不可添加状态分开，避免把其他禁用项画成已勾选。
