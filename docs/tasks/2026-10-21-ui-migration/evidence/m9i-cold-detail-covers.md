# 首次详情等待与返回封面

2026-10-25，patch。用户反馈第一次打开详情空白数秒、返回列表时所有封面刷新。

## 原因与修正

- 播放器首次自定义元素构建及分帧挂载期间，转场提交门隐藏了内容，但没有等待反馈。现在在挂载前插入独立的加载状态，先让出一帧，并在提交完成或导航取消时移除。快速路径延迟淡入，避免每次进入都闪出转圈；顶栏不参与隐藏或动画。此项提供等待反馈，不声称消除首次初始化耗时。
- 已有内存/磁盘封面缓存。旧列表仅在状态对象不变时整体复用；详情中收藏或无关状态刷新导致重建时，已解码图片节点丢失，出现重新加载的视觉效果。现在对新卡片按缓存键、版本及来源匹配，移入原有已解码图片并恢复就绪样式。变化的版本/来源和未解码图片仍正常加载；卡片文字、收藏、评分等按新状态渲染，资源重新订阅和文件校验保持。
- 图片历史缩略图使用同一复用策略；不保留播放器、不扩大 DOM 生命周期，不改变队列、持久化或 IPC。
