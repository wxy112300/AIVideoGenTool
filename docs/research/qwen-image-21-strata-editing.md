## 本项目任务规则

产品入口保持“忠实整理 / 细节增强”两种，不新增六个按钮。Strata 自行理解原指令选择需要的执行细节；没有关键词打分或拒绝器。

1. **去水印、移除**：限定目标及位置，描述移除后露出的区域如何接续；不顺便清掉其他文字或人物。
2. **画质修复**：区分模糊、压缩、噪声与已有纹理；修复不是改色调、换脸、换风格或重新布景。
3. **换视角**：相机变化与主体旋转不同。保留物理场景布局，但允许屏幕构图、遮挡和可见表面随视角变化；不能又要求换视角又锁死原透视。
4. **改变动作**：写最终静态姿态、左右肢体、目标和支撑接触；人物身份、未请求的服装与场景保留，不把旧姿态锁定。
5. **增加、替换、合成**：区分目标画布和身份/姿态/物品/风格供体；补充必要的透视、接触阴影和遮挡，不把供体的整套背景也带进来。
6. **尺寸、位置**：区分厘米等现实尺度、画面占比、像素定位与输出分辨率。保留用户数字及单位；没有标尺时不能假称精确物理测量，也不擅自把 20cm 改成画面 20%。

简单编辑允许短，复杂任务不能只概括为“保持一致并自然融合”。没有最低字数，也不通过无关细节填充篇幅。

## 接入边界

- 自有 profile：`qwen-image-2.1-edit-v1`，源码 `src/core/prompts/qwen-image-2-1/strata.ts`。Qwen 2.1 标准、Turbo、现有 GGUF 变体共用；2511、其他增强后端和 H3 保持原路径。
- 独立 system 契约；用户参考图在前、原始任务和 reference map 随后。没有图时进入 T2I，不假称看见原图。沿用 Flash 非思考采样、32K context、4096 初始输出/自动预算，不引入额外推理轮次。
- 只在请求编译时排除精确匹配的旧共享出厂预设；自定义预设保持，保存设置不迁移、不覆盖。任务显式要求及目标语法优先于附加样式。
- 编辑器使用稳定 Picture 编号；槽位删除后可有缺号。reference map 说明实际输入序号与稳定编号，输出稳定标签交由现有 compiler 重排为真正的 `<imageN>`，含 Paint guide 的插入。参考图不改序，不把 guide 当身份供体。
- 上传阶段进度日志带 profile ID；不记录原图或正文。正常输出沿用图片 normalizer/版本写回与资源生命周期，不添加通用词面门禁。
- 图片页新增文本 token 估算，重用 H3 的同一字符近似算法，明确不含视觉/系统模板，不作为上下文准入、精确 tokenizer 或输出预算。真正 Strata 请求仍由官方 tokenizer 预检和动态预算约束。

## 验证与限制

定向测试覆盖请求路由、消息顺序、预设兼容、参考缺号重映射、原指令保留、短编辑正常写回，以及实际 renderer 清空/增强/输入/入队按钮。它们不证明神经模型能正确判断图像或完成编辑。

真实效果下一步使用上述六类任务，以相同原图、seed、生成模型和步数对照原始指令/旧增强/新增强；记录完整输入输出、耗时、改动忠实度与未修改区域漂移。相机和尺寸尤其不能只凭提示词文本判成功。本次不为静态/UI 修改启动重型 GPU 服务。

本轮结果：70 项定向回归通过；最终完整 `npm.cmd run verify` 为 231 单元文件/2185 项、6 集成文件/89 项、类型检查、生产构建和 20 对比度通过。真实隔离 Electron 在 1440×900、1280×800、900×800 下 token/操作区可见且无横向溢出；实际清空确认保留模型和原生 40 步、Seed/批次数/画布，输入焦点与估算原位更新，关闭重开保持。UI 使用 focus emulation，模型文件不完整的状态不冒充真实成功增强；合成端口旅程另验证实际增强按钮和新任务 ID。忽略目录 `temp/create-smoke-SsOy31/` 保存本地截图及清理报告；测试 PID/端口已退出，没有启动 GPU 模型、生成用户媒体或改正式配置。既有 jsdom scrollTo、构建 chunk 警告不阻断本轮门禁。
