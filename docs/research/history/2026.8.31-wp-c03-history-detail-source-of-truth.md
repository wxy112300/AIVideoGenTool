# WP-C03 History Detail Source-of-Truth Evidence

日期：2026-08-31
基线：`1307574`（C02E，应用版本 `0.56.2`）
范围：History video detail、image detail、renderer capture smoke 与窄屏横向溢出诊断。

## 证据来源

- 当前产品合同：`docs/UX_CONTRACT.md`。Details 要求主媒体与版本 rail 组成一个 viewer，生成信息和主操作在 viewer 附近保持可达；没有要求另行存在 compact action bar 或 `<details>` disclosure。
- 当前生产 DOM：`src/renderer/pages/history/page.ts`。视频和图片详情都使用 `.history-detail-quick-actions`，其中包含 `.history-detail-action-primary`、`.history-detail-action-secondary` 与 `.history-detail-more-actions[role="group"]`；没有 `.history-detail-compact-actions`，也没有 `.history-detail-more` `<details>`。
- 当前可访问性测试：`tests/history-accessibility.test.ts` 已明确要求主操作和具体 `data-*` action selectors，并排除旧的 `.history-detail-more`/compact 结构。
- 当前捕获 harness：`scripts/capture-ux-ui-renderer-baseline.cjs` 的 detail smoke 仍要求 `.history-detail-compact-actions` 与 `.history-detail-more` disclosure，因此它验证的是已淘汰的历史结构，而不是当前 renderer 合同。

## 实际渲染证据

捕获使用真实 Electron `BrowserWindow`、当前 production renderer build 和隔离的 synthetic fixture；由于开发 Vite server 在本机监听 `127.0.0.1:5173` 时返回 `EACCES`，本次使用 `UX_UI_RENDERER_URL=file:///E:/Projects/AIVideoGenTool/dist/renderer/index.html`，不代表 ComfyUI/GPU runtime smoke。

| Fixture | Viewport | document client/scroll | body client/scroll | 诊断结论 |
| --- | --- | --- | --- | --- |
| video detail | 900×800 | 874 / 874 | 874 / 874 | 无页面横向溢出；只有屏幕外 Media Chrome settings/playback menu 测量节点 |
| image detail | 900×800 | 874 / 874 | 874 / 874 | 无页面横向溢出；两个被 `overflow-x:hidden` 裁剪的 fallback `small` 测量节点 |
| video detail | 760×800 | 734 / 734 | 734 / 734 | 无页面横向溢出；同一组屏幕外 Media Chrome 菜单测量节点 |
| image detail | 760×800 | 734 / 734 | 734 / 734 | 无 overflowing 节点，页面横向溢出为零 |

detail smoke 的证据符合当前 DOM：视频 generation record 为 7 条、图片为 5 条；当前 action selectors 全部存在；图片版本数为 2；四个目标视口的两个 fixture 的 `noHorizontalOverflow` 均为 true。原 smoke 失败仅来自 compact/disclosure 两组过时断言。

## 决策

1. 当前生产详情布局符合 `UX_CONTRACT.md`，不为 harness 重新加入已淘汰的 compact bar 或 disclosure DOM。
2. 将 detail smoke 改为检查当前 `.history-detail-quick-actions` action surface、可见主操作、既有 action selectors、generation records、版本入口和 document/body/main 横向边界。
3. Media Chrome 菜单和裁剪 fallback 文本是组件内部/隐藏测量噪声；在 document/body 没有可见溢出的证据下，不修改播放器业务或通用 CSS。
4. 只有在后续四视口 smoke 发现真实可见页面或 action surface 溢出时，才增加最小的现有 token/flex/min-width/wrapping 修复。

## 验收边界

完成 harness 修正后，video detail 与 image detail 均需在 1440×900、1280×800、900×800、760×800 运行 capture smoke；同时运行 History detail/player/accessibility focused tests、typecheck、`npm.cmd run verify`，并复核 diff 不涉及 History 数据、IPC、media identity、播放器业务或 prototypes。
